# Proyecto Formativo en Análisis y Desarrollo de Software - Ficha 2863722

## Descripción
Este proyecto es una iniciativa del Servicio Nacional de Aprendizaje (SENA) diseñada para brindar a los aprendices experiencia práctica en el campo del desarrollo de software. El objetivo es consolidar los conocimientos teóricos y prácticos adquiridos durante el programa de formación, preparando a los participantes para enfrentar los desafíos del mundo laboral en este sector.

## Propósito
El propósito principal es cumplir con los requisitos del programa de formación en Análisis y Desarrollo de Software (ADSO) del SENA. Los aprendices aplicarán sus conocimientos en un entorno práctico, desarrollando habilidades clave como trabajo en equipo, resolución de problemas y comunicación efectiva.

## Enfoque Inicial
La primera fase del proyecto se centra en el levantamiento de requerimientos, un proceso esencial para comprender las necesidades y expectativas de los Stakeholders. Este paso sienta las bases para el desarrollo del proyecto, asegurando que las etapas posteriores se alineen con los objetivos identificados.

## Metodología
Se han realizado dos entrevistas con los Stakeholders para recopilar información detallada, la cual servirá como punto de partida para las siguientes etapas del proyecto.
