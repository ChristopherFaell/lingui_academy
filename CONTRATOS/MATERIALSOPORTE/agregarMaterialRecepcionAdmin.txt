Descripción:
Este endpoint POST se utiliza para agregar un nuevo material de apoyo. Se requiere proporcionar los siguientes datos: nombre, nivel, descripción y enlace.

Endpoint o Path: localhost:3000/api/v1/support-material 
Method: POST 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 

RequestData: json { 
    "name": "string" | Required, 
    "level": "string" | Required, 
    "description": "string" | Required, 
    "link": "string" | Required, 
} 

Response:  

Status: 201 (Ok):  
    Data: { 
        "message": "Material de apoyo agregado exitosamente" 
    } 

Status: 400 (Bad Request):  
    Data: { 
        "message": " Error al agregar el material de apoyo" 
    } 

Status: 500 (Internal Server Error): 
    Data: { 
        "message": "Error en el servidor, intente más tarde" 
    } 

Status: 503 (Service Unavailable):  
    Data: { 
        "message": "Servidor en mantenimiento" 
    }
