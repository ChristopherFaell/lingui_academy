Descripción:
Este endpoint PATCH se utiliza para modificar un material de apoyo. Se requiere proporcionar el nombre, nivel, descripción y enlace del material.

Endpoint o Path: localhost:3000/api/v1/support-material 
Method: PATCH 
Header : { 
Authorization: "bearer fake(caracteres del token) 
} 

RequestData: json { 
    "name": "string" | Required, 
    "level": "string" | Required, 
    "description": "string" | Required, 
    "link": "string" | Required, 
} 

Response:  

Status: 200 (Created):  
    Data: { 
        "message": "Material de apoyo modificado exitosamente" 
    } 

Status: 400 (Bad Request):  
    Data: { 
        "message": " Error al actualizar el material de apoyo" 
    } 

Status: 500 (Internal Server Error): 
    Data: { 
        "message": "Error en el servidor, intente más tarde" 
    } 

Status: 503 (Service Unavailable):  
    Data: { 
        "message": "Servidor en mantenimiento" 
    }
