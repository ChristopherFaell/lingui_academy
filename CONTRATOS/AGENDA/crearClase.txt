Descripción:
Este endpoint POST permite crear una nueva clase en el sistema, proporcionando información detallada como el nombre de la sede, aula, modalidad, nivel, unidad, componente, idioma, fechas de inicio y fin, y duración. Todos los campos son requeridos y deben enviarse en formato JSON. La solicitud debe incluir un token de autorización válido en los encabezados. Si la creación es exitosa, se devuelve un mensaje de confirmación. Si hay errores en los datos o en el servidor, se proporcionan respuestas correspondientes con los códigos de estado apropiados.

Endpoint o Path: localhost:3000/api/v1/agenda-create  

Method: POST  
Header: {  
    Authorization: "bearer fake(caracteres del token)"  
}  

Request Data: Json {  
    "house": "string | required", 
    "classroom": "string | required", 
    "modality": "string | required", 
    "level_": "string | required", 
    "unit_": "string | required", 
    "component": "string | required", 
    "teacher_user_language": "string | required", 
    "class_type": "string | required", 
    "language": "string | required", 
    "start_date_time": "datetime|date|date.notSameAs(end_date_time)",  
    "end_date_time": "datetime | date",  
    "duration_hour": "string | required", // preguntar sobre el required 
}  
     
Request Data: Json {  
    "house_": "A", 
    "classroom": "Tokio",  
    "modality_": "Presencial",  
    "level_": "Intermediate",  
    "unit_": "1B",  
    "component": "Speaking",  
    "teacher_user_language_": "Magdalena",  
    "class_type_": "Técnica",  
    "language_": "Francés",  
    "start_date_time": "2025-04-15T09:00:00Z ",  
    "end_date_time": "2025-04-15T11:00:00Z ",  
    "duration_hour": 2,  
}
