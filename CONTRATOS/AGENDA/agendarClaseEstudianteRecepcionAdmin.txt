Descripción:
Este endpoint POST permite agendar una clase para un estudiante específico. El usuario debe enviar los datos del estudiante y la sesión de clase en formato JSON. La solicitud debe incluir un token de autorización válido en los encabezados para autenticar al usuario. Dependiendo de la respuesta del servidor, se retornarán diferentes códigos de estado que indican el éxito o los errores en el proceso de agendado.

Endpoint o Path: localhost:3000/api/v1/agenda 

Method: POST 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 

Request Data: Json { 
    "student": "string | required", 
    "classroom_session": number | required | positive | withoutDecimals, 
} 

Request Data: Json { 
    "student": "Dyledinson Rozamargo", 
    "classroom_session": 2041, 
} 

Responses: 

Status: 201 (Created):  
    Data: { 
        "message": " Clase agendada exitosamente para el estudiante. " 
    } 

Status: 204 (Not Content):  
    Data: { 
        "message": " No existen clases agendadas " 
    } 

Status: 400 (Bad Request):  
    Data: { 
        "message": " Error al agendar la clase. Verifique los datos suministrados. " 
    } 

Status: 404 (Not Found) 
    Data: { 
        "message": " La clase o el estudiante no se encuentran registrados." 
    } 

Status: 409 (Conflict) 
    Data: { 
        "message": " El estudiante ya se encuentra inscrito en esta clase. " 
    } 

 

Status: 409 (Conflict) 
    Data: { 
        "message": " No hay cupos disponibles para esta clase" 
    } 

Status: 500 (Internal Server Error): 
    Data: { 
        "message": "Error en el servidor, intente más tarde." 
    } 

Status: 503 (Service Unavailable):  
    Data: { 
        "message": "Servidor en mantenimiento" 
    }
