Descripción:
Este endpoint PATCH permite modificar los detalles de una clase agendada, como la sede, el aula, modalidad, nivel, unidad, componente, idioma, fechas y duración. La solicitud debe incluir un token de autorización válido en los encabezados y los nuevos datos de la clase en formato JSON. Si la clase se modifica con éxito, se devuelve un mensaje de confirmación. Si ocurre algún error, se proporcionan respuestas correspondientes con los códigos de estado adecuados.

Endpoint o Path: localhost:3000/api/v1/agenda 
Method: PATCH 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 

Request Data: Json {  
    "house": "string | required", 
    "classroom": "string | required", 
    "modality": "string | required", 
    "level_": "string | required", 
    "unit_": "string | required", 
    "component": "string | required", 
    "teacher_user_language": "string | required", 
    "class_type": "string | required", 
    "language": "string|required", 
    "start_date_time":"datetime | date | 						date.notSameAs(end_date_time)", 
    "end_date_time": "datetime | date",  
    "duration_hour": "string | required", // preguntar sobre el required 
}  
 
Request Data: Json {  
    "house_": "A", 
    "classroom": "Tokio",  
    "modality_": "Presencial",  
    "level_": "Intermediate",  
    "unit_": "1B",  
    "component": "Speaking",  
    "teacher_user_language_": "Magdalena",  
    "class_type_": "Técnica",  
    "language_": "Francés",  
    "start_date_time": "2025-04-15T09:00:00Z ",  
    "end_date_time": "2025-04-15T11:00:00Z ",  
    "duration_hour": 2,  
}  

Responses: 

Status: 200 (Ok):  
    Data: { 
        "message": "Clase modificada exitosamente" 
    } 

Status: 400 (Bad Request):  
    Data: { 
        "message": " Error al modificar la clase" 
    } 

Status: 500 (Internal Server Error): 
    Data: { 
        "message": "Error en el servidor, intente más tarde" 
    } 

Status: 503 (Service Unavailable):  
    Data: { 
        "message": "Servidor en mantenimiento" 
    }
