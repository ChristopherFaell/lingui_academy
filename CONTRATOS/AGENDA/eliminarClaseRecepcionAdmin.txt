Descripción:
Este endpoint DELETE permite eliminar una clase agendada especificando su sesión de aula. La solicitud debe incluir un token de autorización válido en los encabezados y el ID de la sesión de aula en formato JSON. Si la clase se elimina con éxito, se devuelve un mensaje de confirmación. En caso de que no se pueda encontrar la clase o haya un error en el proceso, se proporcionan respuestas con los códigos de estado correspondientes.

Endpoint o Path: localhost:3000/api/v1/agenda 
Method: DELETE 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 

Request Data: Json { 
    "classroom_session":number|required|positive|withoutDecimals, 
} 

Request Data: Json { 
    "classroom_session": 2041, 
} 

Responses: 

Status: 200 (Ok):  
    Data: { 
        "message": " Clase eliminada exitosamente " 
    } 

Status: 204 (Not Content):  
    Data: { 
        "message": " No existen clases agendadas " 
    } 

Status: 400 (Bad Request):  
    Data: { 
        "message": " Error al eliminar la clase " 
    } 

Status: 404 (Not Found) 
    Data: { 
        "message": " La clase no se encuentra registrada." 
    } 

Status: 500 (Internal Server Error): 
    Data: { 
        "message": "Error en el servidor, intente más tarde." 
    } 

Status: 503 (Service Unavailable):  
    Data: { 
        "message": "Servidor en mantenimiento" 
    }
