Descripción:
Este endpoint PATCH permite modificar el avance de un estudiante, actualizando su nivel, unidad y componente. Se requiere una autenticación válida para acceder al servicio. Si la modificación es exitosa, se devuelve un mensaje confirmando el cambio. En caso de error en la solicitud o problemas con el servidor, se devuelve el mensaje adecuado indicando la causa del fallo.

Endpoint o Path: localhost:3000/api/v1/avance 
Method: PATCH 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 

RequestData: json { 
    "level": "string", 
    "unit": "string", 
    "component": "string", 
} 

Response:  

Status: 200 (Ok):  
    Data: { 
        "message": " Se ha modificado exitosamente " 
    } 

Status: 400 (Bad Request):  
    Data: { 
        "message": " Error al modificar el avance" 
    } 

Status: 500 (Internal Server Error): 
    Data: { 
        "message": "Error en el servidor, intente más tarde" 
    } 

Status: 503 (Service Unavailable):  
    Data: { 
        "message": "Servidor en mantenimiento" 
    }
