Endpoint Descripción:
Este endpoint PATCH permite modificar la imagen, correo electrónico y número de teléfono de un usuario en su perfil.

Endpoint o Path: localhost:3000/api/v1/perfil/:id

Method: PATCH
    Request Data: 
            json { 
                "image": "string", //Qué tipo de dato es la imagen
                "email": "string|email",
                "phoneNumber": "string|mobile|min(10)|max(10)",
            }

    Responses: 
        Status: 200 (OK): 
            Data: { 
                "message": "Se modificó lainformación de forma correcta."
            }

         Status: 304 (Not Modified):  
            Data: { 
                "message": "No se pudo modificar la información" 
            }

        Status: 400 (Bad Request):  
            Data: { 
                "message": " Insertar información correspondiente en la casilla estipulada" 
            } 

        Status: 401 (Unauthorized): (gestion a nivel global) 
            Data: { 
                "message": "Usuario y contraseña incorrecta" 
            } 

        Status: 500 (Internal Server Error): (gestion a nivel global) 
            Data: { 
                 "message": "Error en el servidor, intente más tarde" 
            }
