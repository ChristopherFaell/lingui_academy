Endpoint Descripción:
Este endpoint GET genera un reporte de la clase impartida por un maestro, incluyendo información sobre la sesión, como el código de clase, nivel, modalidad y duración.

Endpoint o Path: localhost:3000/api/v1/report/teacher
Method: GET 
 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 
 
RequestData: 
    CODE/ Query Params
 
Response:  
 
	Status: 200 (Ok):  
        Data: json { 
            "date_time": date, 
            "class_code_session": number,
            "level": "string",
            "modality": "string",
            "duration": number,
        } 
 
	Status: 400 (Bad Request):  
        Data: { 
            "message": " Error al obtener el reporte" 
        } 
 
	Status: 500 (Internal Server Error): 
        Data: { 
            "message": "Error en el servidor, intente más tarde" 
        } 
 
	Status: 503 (Service Unavailable):  
        Data: { 
            "message": "Servidor en mantenimiento" 
        }
