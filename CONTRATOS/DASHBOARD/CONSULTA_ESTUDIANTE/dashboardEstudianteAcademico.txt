Descripción:
Este endpoint GET obtiene la información relacionada con el estudiante, incluyendo su código, nivel, unidad, componente actual y un comentario sobre su progreso.

Endpoint o Path: localhost:3000/api/v1/dashboard/estudiante
Method: GET 
 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 
 
RequestData: 
    CODE/ Query Params
 
Response:  
 
	Status: 200 (Ok):  
        Data: json { 
            "code": number,
            "level": "string",
            "unit": "string",
            "component": {
                name: "string",
                check: boolean,
            },
            "comment": "string",
        } 
 
	Status: 400 (Bad Request):  
        Data: { 
            "message": " Error al obtener la información" 
        } 
 
	Status: 500 (Internal Server Error): 
        Data: { 
            "message": "Error en el servidor, intente más tarde" 
        } 
 
	Status: 503 (Service Unavailable):  
        Data: { 
            "message": "Servidor en mantenimiento" 
        }
