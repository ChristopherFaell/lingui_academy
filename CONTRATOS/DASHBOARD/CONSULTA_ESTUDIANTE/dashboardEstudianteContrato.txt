Descripción:
Este endpoint GET obtiene la información sobre el contrato, incluyendo las fechas de inicio y fin estimadas, así como las horas mensuales y semanales asignadas al contrato.

Endpoint o Path: localhost:3000/api/v1/dashboard/contract
Method: GET 
 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 
 
RequestData: 
    CODE/ Query Params
 
Response:  
 
	Status: 200 (Ok):  
        Data: json { 
            "start_date": date,
            "estimated_end_date": date,
            "month_hour": number,
            "week_hour": number,
        } 
 
	Status: 400 (Bad Request):  
        Data: { 
            "message": " Error al obtener la información" 
        } 
 
	Status: 500 (Internal Server Error): 
        Data: { 
            "message": "Error en el servidor, intente más tarde" 
        } 
 
	Status: 503 (Service Unavailable):  
        Data: { 
            "message": "Servidor en mantenimiento" 
        }
