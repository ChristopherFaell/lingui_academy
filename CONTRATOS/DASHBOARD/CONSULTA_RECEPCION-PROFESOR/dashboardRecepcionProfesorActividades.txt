Este endpoint GET recupera información sobre las tareas, proporcionando el nombre, la descripción y la fecha y hora programadas.

Endpoint o Path: localhost:3000/api/v1/dashboard/task
Method: GET 
 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
}

    CODE/ Query Params

        }

            "message": " Error al obtener la información" 
        }

        Data: { 
            "message": "Error en el servidor, intente más tarde" 
        }

            "message": "Servidor en mantenimiento" 
        }
