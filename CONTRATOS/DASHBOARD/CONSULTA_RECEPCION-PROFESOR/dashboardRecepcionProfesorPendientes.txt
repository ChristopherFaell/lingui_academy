Descripción:
Este endpoint GET proporciona información detallada sobre la sesión de clases, como el número de sesión, aula, casa, idioma, número de estudiantes, nivel, tipo de clase, fecha y hora, y duración.

Endpoint o Path: localhost:3000/api/v1/dashboard/task
Method: GET 
 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 
 
RequestData: 
    CODE/ Query Params

        Data: json {

            "house": "string",
            "language": "string",
            "student_number": number,
            "level": "string",
            "class_type": "string",
            "date_time": date,
            "duration": number,
        } 
 
	Status: 400 (Bad Request):
