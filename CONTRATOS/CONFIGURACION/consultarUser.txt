Descripción:
Este endpoint GET permite acceder a la configuración del usuario, devolviendo información sobre el nombre, correo electrónico, rol y opciones de configuración del usuario. Se incluyen posibles respuestas de éxito y error, como problemas de acceso o fallos en el servidor, proporcionando mensajes detallados para cada caso.

Endpoint o Path: localhost:3000/api/v1/settings
Method: GET 
 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 
 
RequestData: 
    CODE/ Query Params
 
Response:  
 
	Status: 200 (Ok):  
        Data: json {
            "name": "string", 
            "email": "string",
            "role": number,
            "option": number, 
        } 
 
	Status: 400 (Bad Request):  
        Data: { 
            "message": " Error al ingresar a configuración" 
        } 
 
	Status: 500 (Internal Server Error): 
        Data: { 
            "message": "Error en el servidor, intente más tarde" 
        } 
 
	Status: 503 (Service Unavailable):  
        Data: { 
            "message": "Servidor en mantenimiento" 
        }
