Descripción:
Este endpoint PATCH se utiliza para modificar los permisos de un rol específico en la aplicación. Los parámetros de configuración de permisos incluyen vistas como el tablero y la agenda, con diferentes opciones como clases, sesiones y lista de estudiantes. El servidor responderá según si la modificación fue exitosa o no.

Endpoint o Path: localhost:3000/api/v1/settings/:rol=0000

Method: PATCH
 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 

    Request Data: 
           queryParmas

     Request Data: 
            json { 
                "view_dashboard": {
                    "dashboard": boolean
                },
                "view_agenda": {
                    "class": boolean,
                    "class_session": boolean,
                    "student_list": boolean,
                    "teacher_session": boolean,
                    "advices": boolean,
                },
                ...
            }

    Responses: 
        Status: 200 (OK): 
            Data: { 
                "message": "Se modificaron los permisos de forma correcta."
            }

         Status: 304 (Not Modified):  
            Data: { 
                "message": "No se pudo modificar los permisos" 
            }

        Status: 400 (Bad Request):  
            Data: { 
                "message": "Marcar información en la casilla correspondiente" 
            } 

        Status: 401 (Unauthorized): (gestion a nivel global) 
            Data: { 
                "message": "Usuario y contraseña incorrecta" 
            } 

        Status: 500 (Internal Server Error): (gestion a nivel global) 
            Data: { 
                 "message": "Error en el servidor, intente más tarde" 
            }
