Descripción:
Este endpoint POST permite la creación de un usuario, proporcionando información como nombre, apellido, tipo de documento, número de documento, correo electrónico, rol, tipo de contrato y jornada laboral. Al ejecutar el request, el sistema devuelve diferentes respuestas según el resultado de la operación, como éxito, error de solicitud o problemas de servidor.

Endpoint o Path: localhost:3000/api/v1/crear-usuario

Method: POST  

Header: {  
    Authorization: "bearer fake(caracteres del token)"  
}  
     
Request Data: Json {  
    "name": "string",
    "last_name": "string",
    "document_type": "string",
    "document_number": number,
    "email": "string",
    "rol": "string",
    "contract_type": "string",
    "workday": "string"
}  

     
Responses: 

Status: 201 (Created):  
    Data: { 
        "message": "Usuario creado exitosamente" 
    } 

Status: 400 (Bad Request):  
    Data: { 
        "message": " Error al crear el usuario" 
    } 

Status: 500 (Internal Server Error): 
    Data: { 
        "message": "Error en el servidor, intente más tarde" 
    } 

Status: 503 (Service Unavailable):  
    Data: { 
        "message": "Servidor en mantenimiento" 
    }
