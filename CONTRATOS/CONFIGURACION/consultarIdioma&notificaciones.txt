Descripción:
Este endpoint PATCH permite actualizar la configuración de idioma y notificaciones del usuario. Se realiza a través de parámetros de consulta (query params) en la solicitud. Si la modificación es exitosa, se devuelve la configuración actualizada. Si no es posible realizar los cambios, se devuelve un mensaje indicando que no se pudo modificar. En caso de error o problemas del servidor, se proporciona el mensaje de error correspondiente.

Endpoint o Path: localhost:3000/api/v1/settings

Method: PATCH
 
Header : { 
    Authorization: "bearer fake(caracteres del token) 
} 

     Request Data: 
           CODE/ Query Params

    Responses: 
        Status: 200 (OK): 
            Data: json { 
                "language": "string",
                "notification": "string"
            }

         Status: 304 (Not Modified):  
            Data: { 
                "message": "No se pudo modificar el idiomas y notificsciones" 
            }

        Status: 400 (Bad Request):  
            Data: { 
                "message": "Elegir información requerida o seleccionar por defecto" 
            } 

        Status: 500 (Internal Server Error): (gestion a nivel global) 
            Data: { 
                 "message": "Error en el servidor, intente más tarde" 
            }
